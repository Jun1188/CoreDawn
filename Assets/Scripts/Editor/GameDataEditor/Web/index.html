건물

포트 표시 — 건물 면에 붙어 바깥으로 번지는 반투명 흐름. 밝은 띠가 포트의 실제 위치이고, 시안 = 입력 · 귤색 = 출력이다.

포트 규칙 — LocalOffset은 풋프린트 안의 셀, Direction은 아이템이 흐르는 방향. 포트가 향한 쪽 이웃 칸이 건물 자신이면 안쪽을 향한 것이라 연결되지 않는다(검증에서 잡힘).

회전 — 0/90/180/270은 Dir.RotateCellCW와 같은 식으로 미리보기한다. 회전 후에도 origin이 왼쪽 아래를 유지한다.

id — 임포트의 기본 키다. 같은 id로 다시 넣으면 기존 에셋을 덮어쓰고(멱등), 바꾸면 새 에셋이 생긴다. 접두 Building: 는 고정이고 뒤쪽만 정한다. 한 번 정한 뒤에는 바꾸지 않는다.

채굴 속도 — 채굴기는 배율만 갖는다. 실제 시간은 광맥 extractInterval ÷ 배율 — "얼마나 캐기 어려운 광맥인가"는 광맥이, "얼마나 좋은 채굴기인가"는 건물이 말한다.

Recipes — 재료 종류가 입력 슬롯보다 많은 레시피는 흐리게 나오고 고를 수 없다. 제련로·제작기 1입력, 조립기 2입력, 제조기 4입력이라는 곡선이 여기서 강제된다.

Ammo Filter — Ammo 타입만 목록에 오른다.

건설 비용 — 배치 시 인벤토리에서 차감, 철거 시 전액 환급. 아이템 목록은 GameData.json(items 포함)을 불러오면 드롭다운으로 채워진다.

모델 — 미리보기는 형태와 크기만 쓴다. 재질은 회색으로 통일해 표시하고, 위치는 모델의 원점(피벗)을 그대로 쓴다 — 유니티에서 놓이는 위치와 같아야 하기 때문이다. 콘솔에 재질·텍스처 경고 (map is not supported 등)가 떠도 무시해도 된다 — 실제 재질은 Unity 가 임포트할 때 처리한다.
JSON에는 파일명만 들어가고, 프리팹은 임포트할 때 자동 생성된다. 임포터가 Assets/Models 에서 같은 이름을 찾아 Assets/Prefabs/Buildings/{id}.prefab 을 만들고 SO에 연결한다.
